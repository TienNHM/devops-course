# Buổi 06 – Git & GitHub Workflow

Tuần 3 · Phase 1 – Engineering Foundation · Slide deck: `slides/01-foundation/`

## Learning objectives

Sau buổi học, bạn có thể: giải thích và áp dụng **Git & GitHub Workflow** vào dự án Club Management.

## Nội dung

Repository, commit, branch, merge, PR, conflict, code review, `.gitignore`

## Cấu trúc buổi (120 phút)

| Thời lượng | Hoạt động |
| --- | --- |
| 15' | Ôn tập buổi trước |
| 30' | Kiến thức + demo của mentor |
| 60' | Hands-on lab |
| 15' | Review, recap |

## Hands-on lab

**Đề bài:** Tạo repository nhóm, thực hành feature branch và Pull Request.

Công cụ: Git, GitHub

### L1 – Foundation (hoàn thành theo hướng dẫn)

Tạo repo, làm feature branch, mở PR và được một bạn review.

### L2 – Engineering (tự triển khai, giải thích, xử lý lỗi)

Chủ động tạo và resolve merge conflict; thiết lập branch protection (yêu cầu PR + review).

## Lỗi thường gặp

- Commit trực tiếp lên main
- Commit nhầm `.env`, `node_modules`
- Resolve conflict bằng cách xóa hết code của người kia

## Nộp bài

Nộp theo `templates/lab-template.md` vào `lab-06/` trong repository cá nhân:
`README.md`, `source/`, `screenshots/`, `evidence/command-output.txt`, `report.md`.
Screenshot không đủ để chấm: phải có source, câu lệnh, log hoặc kết quả kiểm thử.

## Recap

Tự trả lời 3 câu: (1) Vấn đề này giải quyết gì? (2) Nó hoạt động thế nào? (3) Khi lỗi, bạn kiểm tra gì đầu tiên?
