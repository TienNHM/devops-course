# HCMUTE DSC – DevOps Learning Program

Khóa DevOps 16 tuần, 32 buổi bằng tiếng Việt cho thành viên CLB HCMUTE DSC. Bạn tự dựng, tự phá và tự sửa một ứng dụng thật qua Linux, Git, Docker, Compose, GitHub Actions và Kubernetes.

Website khóa học: https://devops-course.tiennhm.io.vn/

## Bắt đầu

1. Đọc [Bắt đầu từ đây](curriculum/getting-started.md).
2. Cài môi trường theo [Cài đặt máy](resources/setup-guide.md).
3. Vào [Buổi 01 – DevOps Introduction](labs/week-01/session-01.md).
