# Chuẩn đầu ra

| Năng lực | Chuẩn đầu ra |
| --- | --- |
| Linux | Sử dụng CLI, quản lý process, permission, service |
| Git/GitHub | Branch, PR, review, conflict resolution |
| Networking | Hiểu IP, DNS, port, TCP, HTTP, reverse proxy |
| Docker | Viết Dockerfile, build, run, debug container |
| Docker Compose | Vận hành hệ thống nhiều container |
| CI/CD | Tự động test, build và publish image |
| Kubernetes | Hiểu kiến trúc cluster và các workload |
| kubectl | Deploy, inspect, debug, scale, rollback |
| DevOps | Xây dựng quy trình tự động hóa có thể tái sử dụng |
| Troubleshooting | Phân tích log, xác định nguyên nhân và khắc phục lỗi |

## Hai mức yêu cầu cho mỗi lab

| Level | Đối tượng | Yêu cầu |
| --- | --- | --- |
| L1 – Foundation | Chưa có kinh nghiệm | Hoàn thành theo hướng dẫn |
| L2 – Engineering | Đã biết lập trình/Git | Tự triển khai, giải thích và xử lý lỗi |

Ví dụ Docker Compose: L1 chạy được Backend và Database; L2 tự viết Compose, thiết lập healthcheck, volume, network và restart policy.
