# Ví dụ Docker

Các ví dụ nhỏ, chạy độc lập, bổ trợ cho Tuần 3-5. Mỗi thư mục có README riêng.

| Thư mục | Nội dung | Buổi liên quan |
| --- | --- | --- |
| `nginx-demo/` | Chạy Nginx, port mapping, bind mount | Tuần 3 |
| `hello-node/` | So sánh `Dockerfile.naive` và `Dockerfile.optimized` | Tuần 3-4 |
| `network-lab/` | User-defined network, DNS theo tên container | Tuần 4 |
| `postgres-volume/` | PostgreSQL, named volume, `pg_dump` | Tuần 5 |

Các ví dụ dùng cổng 38080, 38081 hoặc 35432 trên máy host. Nếu bị trùng, đổi số cổng bên trái dấu `:`.
