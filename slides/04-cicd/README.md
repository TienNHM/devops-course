# Slide deck 04 – CI/CD

GitHub Actions, Workflow, Build, Test, GHCR · 25–30 slides

## Buổi áp dụng

- Buổi 15: CI/CD Fundamentals – Continuous Integration, Delivery, Deployment, Pipeline, Artifact, Runner, Trigger
- Buổi 16: GitHub Actions Basics – Workflow, YAML, Events, Jobs, Steps, Runner, Marketplace Actions
- Buổi 17: Automated Testing – Unit Test, Integration Test, Test Report, Build Validation
- Buổi 18: Docker CI Pipeline – Docker Build, Buildx, cache, tagging, GHCR, authentication
- Buổi 19: CD & Deployment Strategies – Continuous Deployment, environment, secrets, approval, rollback, deployment strategy
- Buổi 20: Pipeline Security – Least Privilege, permissions, secret management, dependency scanning, SBOM, image scanning

## Template mỗi buổi

1. Learning objectives
2. Problem statement – vấn đề thực tế
3. Concept – khái niệm cần hiểu
4. Architecture – sơ đồ giải thích
5. How it works – quy trình hoạt động
6. Demo – giảng viên thực hiện
7. Hands-on lab – học viên tự thực hành
8. Common mistakes – lỗi thường gặp
9. Challenge – bài tập nâng cao
10. Recap – kiến thức cần nhớ

Nguyên tắc: một slide chỉ một ý chính; mỗi câu lệnh có ví dụ đầu vào, kết quả mong đợi và tình huống lỗi.
