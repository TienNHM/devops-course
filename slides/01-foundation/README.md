# Slide deck 01 – DevOps Foundation

SDLC, DevOps, Linux, networking, Git · 30–35 slides

## Buổi áp dụng

- Buổi 01: DevOps Introduction – SDLC, DevOps culture, Dev vs Ops, CI/CD, Infrastructure as Code, deployment lifecycle
- Buổi 02: Development Environment – Windows, WSL2, Linux, Terminal, Shell, package manager, filesystem
- Buổi 03: Linux CLI – `pwd`, `ls`, `cd`, `find`, `grep`, `cat`, `less`, `head`, `tail`, piping
- Buổi 04: Linux Administration – User, Group, chmod, chown, process, systemctl, environment variables
- Buổi 05: Networking Fundamentals – IP, subnet, DNS, TCP/UDP, port, HTTP/HTTPS, localhost, loopback
- Buổi 06: Git & GitHub Workflow – Repository, commit, branch, merge, PR, conflict, code review, `.gitignore`

## Template mỗi buổi

1. Learning objectives
2. Problem statement – vấn đề thực tế
3. Concept – khái niệm cần hiểu
4. Architecture – sơ đồ giải thích
5. How it works – quy trình hoạt động
6. Demo – giảng viên thực hiện
7. Hands-on lab – học viên tự thực hành
8. Common mistakes – lỗi thường gặp
9. Challenge – bài tập nâng cao
10. Recap – kiến thức cần nhớ

Nguyên tắc: một slide chỉ một ý chính; mỗi câu lệnh có ví dụ đầu vào, kết quả mong đợi và tình huống lỗi.
