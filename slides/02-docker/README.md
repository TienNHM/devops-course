# Slide deck 02 – Docker Fundamentals

Architecture, Image, Container, Dockerfile · 30–35 slides

## Buổi áp dụng

- Buổi 07: Container Fundamentals – VM vs Container, Docker Architecture, Docker Engine, Image, Container, Registry
- Buổi 08: Docker CLI – `docker run`, `ps`, `exec`, `inspect`, `logs`, `stop`, `rm`, `pull`, `push`
- Buổi 09: Dockerfile – FROM, WORKDIR, COPY, RUN, ENV, EXPOSE, CMD, ENTRYPOINT, build context
- Buổi 10: Image Optimization – Image layers, caching, `.dockerignore`, multi-stage build, image tagging
- Buổi 11: Container Networking – Bridge network, port mapping, container DNS, network isolation
- Buổi 12: Persistent Storage – Volume, bind mount, tmpfs, database persistence, backup

## Template mỗi buổi

1. Learning objectives
2. Problem statement – vấn đề thực tế
3. Concept – khái niệm cần hiểu
4. Architecture – sơ đồ giải thích
5. How it works – quy trình hoạt động
6. Demo – giảng viên thực hiện
7. Hands-on lab – học viên tự thực hành
8. Common mistakes – lỗi thường gặp
9. Challenge – bài tập nâng cao
10. Recap – kiến thức cần nhớ

Nguyên tắc: một slide chỉ một ý chính; mỗi câu lệnh có ví dụ đầu vào, kết quả mong đợi và tình huống lỗi.
