# Slide 09 – Cloud và IaC (tùy chọn)

> **Tóm tắt:** Module tùy chọn của Lộ trình Nâng cao: chạy AWS cục bộ bằng floci, tạo hạ tầng bằng Terraform và kiểm thử tích hợp trong GitHub Actions. Bộ slide gồm 2 buổi (33 và 34), mỗi buổi học trọn vẹn bằng slide.

## Module này dùng để làm gì

Khóa học chạy hoàn toàn trên máy cá nhân nên chưa có phần cloud và Infrastructure as Code (IaC). Module này bổ sung hai nội dung đó mà không cần tài khoản AWS và không phát sinh chi phí, nhờ [floci](https://github.com/floci-io/floci), một bộ giả lập AWS mã nguồn mở. Đây là bộ giả lập, không phải AWS thật; hành vi có thể khác ở một số dịch vụ.

Điều kiện: đã học xong phần CI/CD của Lộ trình Nâng cao (buổi 15 đến 20) và dùng được Docker, Compose, Git, GitHub Actions.
