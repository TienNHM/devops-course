# Slide deck 08 – Capstone

Architecture, deployment, security, demo · 20–25 slides

## Buổi áp dụng

- Buổi 29: Architecture & Planning – Requirement, architecture, container design, CI/CD design, task breakdown
- Buổi 30: Implementation – Docker, Compose, Kubernetes, GitHub Actions, testing
- Buổi 31: Testing & Troubleshooting – Deployment test, failure injection, logs, security checklist, performance basics
- Buổi 32: Final Demo & Review – Product demo, pipeline walkthrough, architecture presentation, lessons learned

## Template mỗi buổi

1. Learning objectives
2. Problem statement – vấn đề thực tế
3. Concept – khái niệm cần hiểu
4. Architecture – sơ đồ giải thích
5. How it works – quy trình hoạt động
6. Demo – giảng viên thực hiện
7. Hands-on lab – học viên tự thực hành
8. Common mistakes – lỗi thường gặp
9. Challenge – bài tập nâng cao
10. Recap – kiến thức cần nhớ

Nguyên tắc: một slide chỉ một ý chính; mỗi câu lệnh có ví dụ đầu vào, kết quả mong đợi và tình huống lỗi.
